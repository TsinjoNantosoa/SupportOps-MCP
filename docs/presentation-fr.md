# Présentation courte

SupportOps MCP est un copilote de support informatique local utilisant deux vrais serveurs MCP : l'un consulte des tickets fictifs dans SQLite, l'autre recherche des procédures Markdown autorisées. L'agent OpenAI peut analyser et préparer une proposition, mais seule la CLI de confiance peut l'approuver après confirmation humaine. La transaction vérifie la session, l'expiration et la version du ticket, puis journalise la décision. Toutes les données sont fictives et aucun système d'entreprise réel n'est connecté.
