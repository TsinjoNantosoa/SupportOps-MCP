# SupportOps MCP V2.2 — rapport de release

## A. Executive summary

V2.2 renforce le copilote existant sans reconstruire le dépôt : secrets retirés de l'exemple, instructions agent durcies, rejeu d'approbation lié à l'identité, tests ciblés ajoutés et documentation complète créée. Les parcours MCP déterministes, le runtime Docker et l'import n8n isolé sont vérifiés ; l'OpenAI live, l'exécution des workflows IA et le navigateur n8n restent explicitement non vérifiés faute de credential.
